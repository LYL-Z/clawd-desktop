# Clawd 壁纸源构图

这两张壁纸是任务书第 10 节的独立 4K 构图，由已经批准的同源像素素材组合导出。未生成新角色，未重画身体、眼睛、道具或放射标记轮廓，也没有把整张图集拉伸为壁纸。

`composition.json` 是当前构图参数；`composition-first-preview.json`、`composition-second-preview.json` 和 `composition-third-preview-original-colour.json` 仅保留设计比较，不是当前交付参数。`source-manifest.json` 记录当前源文件的实际 SHA-256、裁切行列与字体关联。目录中的透明 PNG 是这些源文件的精确裁切，`wizard.png` 仅把同一默认身体与已批准的帽/杖层组合。

## 两色与遮挡

浅版衬底为 `#FAF9F5`，深版为 `#141413`。所有蟹、方眼、帽子与持物保留源 RGB，不做霓虹改色。

为了让后方标记与同色的前景身体分离，只有标记使用 `backgroundBlendOpacity: 0.55`：每个源 RGB 样本按 55% 原色与 45% 本版衬底合成；源 alpha、轮廓、比例与整像素尺度保持不变。这是确定性的对比调整，未补画任何轮廓。`composition-third-preview-original-colour.json` 可重复导出对比调整之前的版本。

只有标记允许被前景主蟹遮挡。当前交付标记保留 86.4736% 的不透明像素可见（遮挡 13.5264%）；这不是整个包围盒面积比例。实际比例由导出器按不透明像素计算，写入 `qa/wallpapers/wallpaper-qa.json`。主蟹、巫师和四持物小蟹要求完全不被遮挡；最终 PNG 内每个可见像素必须与对应合成源像素精确一致。

## 重复导出

从项目根目录运行：

```powershell
python .\scripts\export-wallpapers.py
```

依赖为 Pillow。导出器固定输出 3840×2160 RGB 无损 PNG，两张文件位于 `exports/wallpapers/`，缩略预览和结构报告位于 `qa/wallpapers/`。修改 `composition.json` 可调整文字、锚点、整数倍率、衬底和点阵参数；不会自动更换 Windows 壁纸。

当前参数锁定源素材与本机字体的 SHA-256。若它们变化，导出器会停止，避免在不知情时换成另一版角色或字体。应先检查新源，再明确更新参数中的预期哈希。若其他电脑没有该系统字体，可使用本地具有适当许可的粗体无衬线字体，并更新路径、字号、预期哈希及视觉检查；原版字节一致性需要相同字体字节与导出环境。
