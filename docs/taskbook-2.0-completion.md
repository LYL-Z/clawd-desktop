# Clawd 2.0 增量升级任务书完成度与验收记录

更新日期：2026-10-20。对应用户提供的 `CLAWD 2.0 — Windows 桌面像素伙伴全方位优化与增量开发任务书`。任务书中的“2.0”是工作方案名称，不强制改变语义版本；本轮按实际变更继续使用 `1.1.0`。

### 版本决策

任务书第十八章明确要求“版本号必须按照实际变更与项目版本约定确定”，并说明不得仅因任务书称为 Clawd 2.0 就强制把 `package.json` 改为 2.0.0。本轮从仓库公开的 1.0.1 基线继续增量开发，保留旧设置迁移与原有功能兼容，因此候选包按 SemVer 次版本递增为 **1.1.0**。它是正式版本候选，不是临时过渡包；只有发布门槛通过后才会建立 1.1.0 tag 和 GitHub Release。

## 更新分发与地域范围

桌面更新器支持用户主动查询、选择下载、HTTP Range 续传、双来源回退和长度/SHA-256 校验。GitHub Release 是版本与安装包唯一发布源。只读预检确认 `chronokalamos.com` 是 Active Free Website zone，精确子域 `clawd-updates.chronokalamos.com` 没有 DNS 记录或 Worker Custom Domain；账号已有的 `jiuxiao-ses-callback` 未修改，Clawd Worker 尚未部署。Cloudflare OAuth 的订阅接口因缺少 Billing Read/Write scope 返回 403，故不能据该接口断言 Workers 账户级套餐或账单；不会升级 Workers 计划或创建 R2/付费资源。下一步只尝试部署独立 `clawd-updates` Worker 和该专属主机名，若平台要求付费升级即停止。
