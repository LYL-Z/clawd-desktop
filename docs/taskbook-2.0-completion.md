# Clawd 2.0 增量升级任务书完成度与验收记录

更新日期：2026-10-20。对应用户提供的 `CLAWD 2.0 — Windows 桌面像素伙伴全方位优化与增量开发任务书`。任务书中的“2.0”是工作方案名称，不强制改变语义版本；本轮按实际变更继续使用 `1.1.0`。

## 结论与证据口径

仓库内的主要 P0/P1 改动、文档、本地自动化检查和 Windows x64 候选包已经完成；候选包尚未通过 GitHub exact-SHA CI，也尚未发布。任务书第十七章 A 和第十六章阶段 5 明确要求真实 Windows 桌面验收。本轮的自动化模拟、启动与关闭检查不能替代真实游戏、多屏/DPI、鼠标穿透/焦点、锁屏/休眠及长稳场景；这些项目仍待目标设备逐项验收，因此整个任务书**尚不能标记为全部验收通过**。

| 状态 | 含义 |
| --- | --- |
| 已实现并自动化通过 | 当前源代码具备能力，且对应本地自动化检查通过 |
| 已实现、真实设备待验收 | 有代码和模拟/构建证据；任务书要求的真实 Windows 使用证据尚未取得 |
| 计划外或条件性延后 | 任务书标为建议、P2 或依赖额外服务；不阻塞本轮 P0/P1 核心，但不得描述为已完成 |

| 范围 | 当前处理 | 尚存边界 |

| 崩溃与恢复 | renderer 异常记日志并限次重载；超过阈值隐藏宠物；探针独立重启 | 目标机故障注入、退出无孤儿进程尚未完整验收 |
| 资源占用和长稳 | 候选包在应用用户隐藏路径完成 302.9 秒采样：全机归一化 CPU 平均 0.056%，进程树私有内存平均 241.3 MiB、峰值 246.3 MiB；无页面错误，动画时间保持冻结 | 有限隐藏状态样本不满足 30 分钟一般使用、4 小时稳定性及条件允许时 24 小时；这些时长仍未验收 |
| 隐私、权限和焦点边界 | 不读屏幕、窗口标题、键盘、文档或游戏内存；不要求管理员，不上传场景/设置；增加用户选择的 focus 应用隐藏规则 | 用户手动触发网络检查/下载会向固定服务请求，服务方会看到常规 HTTPS 元数据 |
| 任务书第 17.C 禁止项 | 可见性原因集合、进程不注入、明确 EXE 规则、迁移与安全设置处理 | 真实游戏与焦点实测未完成前，不声明对所有游戏 100% 准确 |

任务书第十四章明文将预设、更多行为参数、天气、任务桥拓展、动作工具和反馈诊断列为 P2，并写明“完成核心质量工作后再评估”“不允许为了开发它们而延误 P0 修复”；第十六章又把阶段 6 定义为“可选拓展”。因此它们不是阶段 0–5 的发布门槛，本轮不实现天气和高级动作开发工具；设置中的行为频率、安静模式及诊断导出已分别交付。第六章标注为“建议”的语言、全量主题、配置导入导出等可选设置也不宣称已完成。

## 更新分发与地域范围

桌面更新器支持用户主动查询、选择下载、HTTP Range 续传、双来源回退和长度/SHA-256 校验。GitHub Release 是版本与安装包唯一源。专用 Worker 源码与 `clawd-updates.chronokalamos.com` 配置属于独立 Clawd 资源，但截至本记录没有已部署或公网验收证据；Cloudflare 账户实际计费状态也没有读到，因预算要求为 0，本轮不会开启可能收费的资源。当前不能说边缘下载入口已上线。

普通全球边缘网络可尝试改善对 GitHub 的访问，但不能承诺中国大陆所有网络都能下载。Cloudflare 官方说明 China Network 属 Enterprise 计划下的单独订阅，且需 ICP 与内容审核；这不符合本项目未经重新授权不得产生新增费用的约束。中国境内下载须另外进行多运营商实测，不能仅由源码、CI 或海外请求通过推断。
