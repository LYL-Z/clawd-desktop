# Clawd Desktop 1.1.0

Clawd 1.1.0 在 1.0.1 基础上增量完善 Windows 场景管理、设置体验、诊断隐私与手动更新。项目仍使用既有 Canvas 像素图集和原生探针；没有重写角色身份、接入云端 AI、采集屏幕/键盘内容或修改其他项目的服务配置。

状态：候选版本，GitHub Release 尚未创建
基线版本：1.0.1
候选源码：见当前分支的精确 Git SHA 与对应 Windows CI

任务书称为“Clawd 2.0”的是本轮升级方案名称；任务书第十八章明确版本应依据实际变更与项目版本约定，不能只因方案名称强制改为 2.0.0。1.1.0 是兼容性增量版本，不是临时过渡包。

## 新增

- 以可见性原因集合协调用户隐藏、游戏、专注应用、全屏、锁屏、挂起与 Renderer 故障；前台 EXE 规则由用户显式配置，不对所有游戏作识别承诺。
- 设置中心提供游戏/专注/例外规则、衣柜预览、安静模式、自主行为频率、双击动作和显示恢复等设置；旧设置迁移到 schema v2。
- 本地诊断采用有界轮转；导出前显示脱敏预览，用户确认后再选择保存位置。
- 更新检查需用户手动触发。发现版本后可选择下载；支持 HTTP Range 续传、GitHub 回退、文件长度与 SHA-256 校验。更新不会自动执行、安装或替换正在运行的便携版。
- 提供独立 Clawd Cloudflare Worker 源码和子域配置，但 Worker **尚未部署**；当前可用版本信息和更新文件均来自 GitHub Releases。没有启用可能产生费用的 Cloudflare 服务，也没有修改九霄或其他项目的域名、Worker 或路由。

## 调整

- 隐藏时暂停 Renderer 动画与命中测试；注视方向加入迟滞；保留原有动作、服饰、物理、四场演出及任务状态桥。
- 设置持久化迁移到 schema v2，延续旧版本用户设置；具体兼容检查见下文。

## 修复与回归保护

- 加入可见性原因并行仲裁的回归保护，确保手动隐藏不会被游戏结束覆盖，并让锁屏、挂起、专注和 Renderer 故障分别恢复。
- 加入原生探针失联、设置迁移和显示环境变化的自动化回归检查。

## 安全与隐私

- 保持本地优先：不新增遥测、模型 API、账号服务、屏幕内容或键盘文本采集。
- 只有用户主动检查/下载时才请求固定更新来源；请求不包含用户设置或游戏/专注规则。诊断导出需要先预览并由用户确认。
- 便携程序未签名；SHA-256 是完整性校验，不是代码签名或发布者身份认证。

## 兼容性与升级

- 基线为公开仓库记录的 1.0.1；旧设置迁移到 schema v2，既有角色动作、服饰、物理、演出、状态桥和 Codex 宠物素材继续保留。
- 仅提供 Windows x64 portable EXE；不是 MSI/NSIS 安装向导。更新需用户主动检查、选择下载、关闭旧程序后手动运行新文件；不会自动安装或替换正在运行的程序。
- 便携包未签名；SHA-256 可检测文件与清单是否一致，不能证明发布者身份。不要为运行程序关闭 Windows 安全保护。
