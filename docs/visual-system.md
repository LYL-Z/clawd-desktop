# Clawd 角色视觉系统

更新日期：2026-10-19。本文以当前运行时图集、动画 Manifest、服饰注册表和 `docs/element-provenance.md` 为准，记录一套用于继续制作与回归检查的像素规范。Clawd 是基于用户提供的 Claude/Clawd 参考所作的非官方衍生粉丝作品；本文不表示 Anthropic 官方授权或品牌规范。

## 角色身份

Clawd 的识别核心是一只陶土橙色、四条短腿、两只黑色方眼的小蟹。身体采用简洁的像素块轮廓，左右有短小横向钳臂；核心身体不画嘴、鼻子、描边、渐变或投影。眼睛与腿的数量、身体比例、陶土色和轮廓在各动作及服饰下保持可辨认。服装可以改变主题，但不能把角色改造成其他角色或泛化的 AI 吉祥物。

风格依据是本项目保留的用户参考图、来源记录与已接纳的运行时素材。没有从 Claude 产品图标、Anthropic 标识或其他品牌素材推导新的图形标志；需要新增 Claude/Clawd 关联元素时，先登记其来源和衍生关系。用户参考与二次整理只证明项目创作依据，不构成第三方许可。

## 运行时像素坐标

| 属性 | 当前值 | 用途 |
| --- | --- | --- |
| 核心图集 | `assets/runtime/core.webp`，1536 × 2288 px | 8 列 × 11 行的运行时动画单元 |
| 动画单元 | 192 × 208 px | 身体、动作与方向帧统一的像素坐标系 |
| 锚点 | (96, 184) | Renderer 的角色落地与位置基准 |
| 中性待机实体包围盒 | x=25…166、y=90…182（右、下边界不包含） | 来自当前 idle 首帧的透明像素边界，用于检查留白与裁切 |
| 中性头顶参考点 | (96, 90) | 比例与头顶位置检查 |
| 中性右眼中心参考 | 约 (126, 107) | 双眼间距与视线帧一致性检查 |
| 地面基准 | y=184 | 腿部落地，不得在静止帧悬空或陷入地面 |
| 核心角色色 | `#DA7758` | 从当前核心像素统计出的陶土色 |
| 眼睛色 | `#141413` | 从当前核心像素统计出的近黑色 |
| 透明色 | alpha=0 | 图集背景必须透明；核心身体不使用半透明边缘 |

上述几何是当前资源的测量值，不是要求所有姿势都落在同一个静止包围盒内。动作可以改变肢体轮廓，但锚点、角色身份与画布边界需保持正确。运行时 Canvas 对像素素材关闭平滑；任何缩放都必须保留硬边和二值透明边缘。

## 配色与材质

- 核心身体只使用登记的陶土橙、眼睛近黑和透明像素；新增阴影或高光要先进入素材并通过像素回归，不可由 CSS/Canvas 模糊制造。
- 服饰保留各自经来源记录的有限像素调色板。服饰颜色不反向改变核心身体颜色。
- 设置界面使用与角色相协调的温暖中性桌面 UI：陶土强调色 `#D97757`、深色文字 `#141413`、暖白底 `#FAF9F5`。UI 色与运行时身体实测色用途不同，不应合并成一个“官方品牌色”。
- 透明区是实际 alpha=0，不得用白底假透明；缩放采用像素保真的最近邻路径。

## 动作、方向与服饰

动画位置与帧节拍以 `assets/runtime/animations.json` 为唯一运行时索引。当前 Manifest 声明 192 × 208 单元、(96,184) 锚点和 16 向注视帧；新增动作必须登记素材、帧范围、时长、循环策略与回归样例。

服饰叠层以同一 192 × 208 身体单元注册，注册数据在 `assets/source/outfits/runtime-registration.json`，来源与处理记录在 `assets/source/outfits/`。头戴物可跟随头部，地面或轨迹道具需要明确自身参考位置。制作时不得为了让配件合身而单独缩放身体，不得遮住两只眼睛、改变四腿拓扑或让主体超出画布。

## 验收方法与证据边界

`scripts/qa-layout.mjs` 使用真实 Electron Renderer，覆盖软件 DPR 1.00、1.25、1.50、1.75、2.00，并额外覆盖本机报告的 2.50 缩放；再组合 0.75、1.00、1.25、1.50 角色尺寸、所有可显示服饰、idle/wave/jump/held/thrown/landing/turn/sway 姿态和多个时间点，检查实体非空、画布内无裁切、透明边缘仍为二值 alpha；同时注入负坐标工作区验证位置恢复。该检查是渲染与坐标模拟，不会改变 Windows 显示设置，也不等于真实多屏/DPI、显示器热插拔或 Codex 宿主验收。

视觉图集还由 Python 图像测试检查尺寸、透明性和资源结构。接纳任何新增视觉资源前应保留来源、原始文件摘要、处理方式和中性注册参照，并检查静止图、关键动作帧、透明边缘与所有受影响服饰。动态道具在不同动作中的真实附着质量需另行人工检查；像素几何测试不能证明艺术审美已通过。
