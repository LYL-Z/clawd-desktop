审查了原仓库代码、可见性与设置模块、Electron 主进程/Preload/Renderer、原生探针、Codex 宠物资源、运行时动画与服饰注册、QA 脚本、CI 工作流、用户任务书及既有公开文档。实施只改动当前 Clawd 仓库工作区。

本文分别记录源码能力、自动化结果、Windows 构建、GitHub exact-SHA CI、公开 Release 和人工设备体验。模拟全屏/游戏输入不等于实际游戏，多组 Electron 软件 DPR 不等于 Windows 真正的多显示器/混合 DPI，构建成功不等于焦点/锁屏行为验收通过。未取得证据的项目仍标为待验收。

## 运行架构与数据边界

- **Electron 主进程**持有设置、透明窗口、托盘、显示器信息、场景仲裁、更新请求、诊断文件和本地任务状态轮询。
- **Preload**通过 `contextBridge` 暴露窄接口；Renderer 使用 sandbox/context isolation，不拥有 Node 文件系统能力。
- **Renderer**绘制运行时像素图集，驱动动作/物理/注视/服饰叠层，并按用户设置运行自主行为。
- **共享逻辑**分别由 `src/shared/visibility.ts`、`settings.ts`、`animation.ts`、`physics.ts`、`behaviour.ts` 管理可见性、迁移/校验、帧与注视、抛掷物理和行为策略。
- **原生探针**只读前台应用元数据、窗口几何、鼠标按下和用户规则指向的游戏进程；不注入进程、不读屏幕/游戏内存/标题/键盘，不要求管理员。
- **诊断模块**只写 `%APPDATA%\Clawd\logs\clawd.jsonl`；导出前在设置页预览经筛选的数据，主进程只保存预览中用户确认的内容。
- **设置协议**schema v2；迁移、合法值归一化、串行写入与原子替换在 `src/electron/services/SettingsStore.ts`；未知字段忽略，不把历史有效设置整体清空。
- **Codex 宠物包**只包含宿主可读的本地素材和描述，不承载 Windows 程序的互动菜单、衣柜或系统窗口行为。

## Windows 场景策略

默认 smart 模式只在用户规则命中当前前台游戏/专注应用或启用全屏隐藏时隐藏。game-running 模式只根据用户规则命中的游戏进程保持隐藏，可覆盖 Alt+Tab 回桌面情况。manual 模式关闭自动游戏/专注/全屏隐藏。用户例外只抑制 smart 自动原因，不能清除手动、锁屏、挂起原因；锁屏和系统挂起始终阻止宠物显示。

可见性记录在原因集合中；进入自动隐藏需稳定 400 ms，离开后按设置等待 500–5000 ms，默认 900 ms。原生探针心跳失效时保留最后的自动阻止原因，避免未知状态下突然显示挡住游戏；探针恢复后重新采样。

## 本轮实现的用户能力

- 用户可为常用办公应用添加“专注时隐藏”规则，规则仅按本机所选 EXE 路径/文件名匹配。
- 安静模式将桌宠固定在当前位置、停止自主巡游，并把自主行为降至至少 60 秒间隔；用户手动互动仍可执行。
- 自主行为节奏提供 calm 45–75 秒、standard 20–35 秒、lively 12–22 秒；双击可选默认演出、挥手、歪头或无特殊动作。
- 显示器 bounds/workArea/scaleFactor 变化会刷新宠物窗口几何；脱离屏幕时可用“收回当前屏幕”恢复位置，且不会清除隐藏原因。
- 注视方向加入迟滞以减少临界角抖动。
- 诊断页提供只读预览与用户选址导出，日志大小有界并有限轮转。

## 更新分发状态与隔离

更新器只由用户触发，支持 latest Release 检查、明确同意后选择下载、HTTP Range 续传、固定仓库 URL 限制、长度及 SHA-256 校验和失败后 GitHub 源回退。更新不会自动执行、安装或替换正在运行的 EXE。

Clawd 更新 Worker `clawd-updates` 已部署，版本 ID `77e92a01-7b3f-488e-83f3-1b540ff4b91c`。v1.1.1 发布后，workers.dev metadata 返回 tag、大小和预期摘要；healthz 为 200，Range 为 206，越界 Range 为 416，HEAD 为 200，自定义域名按设计 307 至固定 workers.dev origin。完整 99,969,008 字节 Worker 下载的 SHA-256 与公开 GitHub asset 及本地产物匹配。没有改动区域级 TLS/PQ、九霄、GlassDesk、DNS 或其他 Worker。用户报告 Workers Free，但 OAuth 无 Billing Read，套餐及额度余量未独立核实；未新增付费资源。中国境内网络可达性仍未实测。

## 尚未验收的硬性设备场景

1. 真实全屏、无边框、窗口化游戏的进出、Alt+Tab、后台运行和崩溃恢复。
2. 游戏切分辨率、主副屏不等高/上下排列/负坐标、混合 DPI 100/125/150/175/200%、副屏全屏、热插拔与休眠后显示器编号变化。
3. 实际焦点不抢占、透明区鼠标穿透、托盘手动隐藏/恢复、Windows 锁屏/解锁/休眠。
4. 注入 Renderer/原生探针异常并确认恢复、退出不留子进程。
5. 长稳门槛已按用户 2026-10-21 明确指示从 4 小时调整为沿用此前约 1 小时观察。先前记录为 3,481.287 秒；最终 1.1.1 包另有 6,482 秒中断观察，但未生成完整结束报告。故障注入与条件允许时的 24 小时观察仍未执行；见稳定性记录。
6. 中国境内多运营商/线路的真实更新下载仍未实测；全球公网 Worker 已部署并完成海外公网 endpoint 检查。
