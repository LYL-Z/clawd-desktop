CLAWD · 从欢迎屏走出的传奇

启动：双击 Clawd.exe；便携版双击 Clawd-版本号-windows-x64.exe。
退出：系统托盘找到橙色小蟹，右键选择“退出”。
找回：托盘右键“收回当前屏幕”，或双击托盘小蟹。

单击小蟹：挥手。
双击：海报演出。
长按：动作菜单。
拖动后松手：按移动速度抛出，落地后回稳。
透明背景：鼠标穿透到下方应用。演出文字、粒子与配角也默认穿透。
右键：显示/隐藏、自动隐藏模式、衣柜、动作、演出、设置、动作剧场、暂停与退出。

游戏与全屏场景：打开“设置与游戏规则”，添加实际游戏的 EXE。默认使用完整路径匹配；只有切换为“文件名”后才匹配不同目录下的同名程序。
智能模式在已配置游戏处于前台时隐藏；启用全屏规则后，也会在全屏应用前隐藏。
“游戏运行期间”模式会在已配置游戏进程仍运行时保持隐藏，包括 Alt+Tab 返回桌面。
“手动控制”关闭游戏和全屏自动隐藏。锁屏和系统挂起仍会隐藏。
离开自动隐藏场景后默认延迟 0.9 秒恢复；可在设置中调整。托盘会提示当前隐藏原因。

设置中心：从托盘菜单打开“设置与游戏规则”。设置保存在 %APPDATA%\Clawd\settings.json。
“收回当前屏幕”只修复位置，不会解除手动、游戏或系统隐藏状态。

版本检查：设置中心 > 隐私与关于 > 检查新版本。只有点击时才向 GitHub 查询公开 Release；发现更新后由用户选择是否打开下载页。程序不会自动下载、安装或替换自身。便携版更新前请退出旧版本，并先核对新文件的 SHA-256。

默认原地、无声。首次运行有一次欢迎演出。
28个动作、8套可选造型、4场演出可在托盘菜单与动作剧场主动预览。
柔软歪头姿态已保留在“歪头打量与回稳”里。
开机启动与本地任务状态桥默认关闭；可在设置中心启用。启动时显示偏好与游戏规则也在设置中心管理。
状态桥只读应用数据目录下的status.json，实际位置见“关于”。
默认位置为 %APPDATA%\Clawd\status.json。
程序不会自动连接Claude/Codex会话，也不会读取屏幕内容、剪贴板或聊天内容。场景探针只读取前台窗口和用户明确添加的 EXE 元数据。
日常运行不联网；手动版本检查会请求 GitHub 的公开 Release 版本信息，不会上传本地设置或应用规则。
