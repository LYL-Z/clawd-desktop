CLAWD · 从欢迎屏走出的传奇

启动：双击 Clawd.exe；便携版双击 Clawd-版本号-windows-x64.exe。
退出：系统托盘找到橙色小蟹，右键选择“退出”。
找回：托盘右键“收回当前屏幕”，或双击托盘小蟹。

单击小蟹：挥手。
双击：默认海报演出，可在设置中心改为挥手、歪头或不触发特殊动作。
长按：动作菜单。
拖动后松手：按移动速度抛出，落地后回稳。
透明背景：鼠标穿透到下方应用。演出文字、粒子与配角也默认穿透。
右键：显示/隐藏、自动隐藏模式、衣柜、动作、演出、设置、动作剧场、暂停与退出。

安静模式：托盘菜单或设置中心均可切换。开启后保持当前位置、停止自主巡游并降低自主动作频率；仍可低频待机和手动互动。自主行为频率可选安静、标准、活泼。

游戏与全屏场景：打开“设置与游戏规则”，添加实际游戏的 EXE。默认使用完整路径匹配；只有切换为“文件名”后才匹配不同目录下的同名程序。
智能模式在已配置游戏处于前台时隐藏；启用全屏规则后，也会在全屏应用前隐藏。
“游戏运行期间”模式会在已配置游戏进程仍运行时保持隐藏，包括 Alt+Tab 返回桌面。
“手动控制”关闭游戏和全屏自动隐藏。锁屏和系统挂起仍会隐藏。
可添加“专注时隐藏的应用”规则；该规则只在智能模式对匹配的前台应用生效。例外应用只覆盖自动游戏/全屏/专注隐藏，不会覆盖手动隐藏、锁屏或系统挂起。
离开自动隐藏场景后默认延迟 0.9 秒恢复；可在设置中调整。托盘会提示当前隐藏原因。

设置中心：从托盘菜单打开“设置与游戏规则”。设置保存在 %APPDATA%\Clawd\settings.json。
“收回当前屏幕”只修复位置，不会解除手动、游戏或系统隐藏状态。
高级诊断：可先查看本地诊断预览，再选择导出 JSON。日志只保存在本机并有大小上限；预览会排除规则名称和路径、窗口标题、任务内容、截图与原始进程路径。只有点击导出并选择位置后才会创建导出文件。

版本检查：设置中心 > 隐私与关于 > 检查新版本。只有点击时才查询 Clawd 专属的固定 workers.dev 更新入口；自定义域名只将合法请求重定向到该入口，服务不可用时回退到 GitHub 公开 Release。发现更新后可选择分块续传下载，完成时核对文件长度和 SHA-256；程序不会自动执行、安装或替换自身。便携版更新前请退出旧版本，并从项目发布页核对哈希。网络检查会让服务收到常规 HTTPS 请求元数据，不会上传本机设置或应用规则。

默认原地、无声。首次运行有一次欢迎演出。
28个动作、8套可选造型、4场演出可在托盘菜单与动作剧场主动预览。
柔软歪头姿态已保留在“歪头打量与回稳”里。
开机启动与本地任务状态桥默认关闭；可在设置中心启用。启动时显示偏好与游戏规则也在设置中心管理。
状态桥只读应用数据目录下的status.json，实际位置见“关于”。
默认位置为 %APPDATA%\Clawd\status.json。
程序不会自动连接Claude/Codex会话，也不会读取屏幕内容、剪贴板或聊天内容。场景探针只读取前台窗口和用户明确添加的 EXE 元数据。
日常运行不联网；手动版本检查/下载会请求 Clawd 专属更新 Worker 或 GitHub 的公开 Release，不会上传本地设置或应用规则。Worker 已部署到固定 workers.dev 主机；正式版本与安装文件仍以 GitHub Release 为唯一来源。普通全球网络入口不保证中国大陆所有运营商和时段均可达。
