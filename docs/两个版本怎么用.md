# Clawd 的两个版本怎么用

## 现在 Codex 中的小蟹

这是本地 V2 图集包 `dist/pet-v2`：提供九类基础状态与16向注视图集，具体播放与触发由宿主决定。它没有装入本项目独立 Windows 程序的菜单或逻辑，所以不会出现本项目的衣柜、长按动作选择、物理抛掷和四场演出入口。

用户已确认实际 Mini 显示正确且会动，原先显示默认角色的问题不再复现。没有扩展菜单是这份包的当前范围，不应再为此重复安装或清除缓存。

九类基础状态是待机、左右移动、挥手、跳跃、失败恢复、等待、工作和检查。提供图集不等于这些状态都能在宿主中手动点播；目前未逐项验证各状态与16向的实际触发。

## 完整互动与衣柜

从[项目 Releases](https://github.com/LYL-Z/clawd-desktop/releases/latest)下载 Clawd 1.0.1 Windows 便携版。这是独立运行的桌宠，有本项目自己的互动和菜单；不会把菜单加到 Codex Mini 上。1.0.0 为早期历史构建，早于当前源码。

| 操作 | 效果 |
| --- | --- |
| 右键小蟹 → 衣柜 | 欢迎蟹、耳机、滑板、巫师、安全帽、侦探、厨师、牛仔，共8套可选造型 |
| 单击小蟹 | 挥手 |
| 双击小蟹 | 海报演出 |
| 长按小蟹 | 动作选择菜单 |
| 拖动后松手 | 提起、抛掷、落地回稳 |
| 右键 → 主题演出 | 欢迎屏、海报、陶土星印、小蟹合奏 |
| 右键 → 动作预览与逐帧检查 | 打开动作剧场，选择动作、服饰、16向和演出 |
| 系统托盘橙色小蟹 → 退出 | 关闭独立桌宠 |

共有28个动作条目，其中部分共享身体并配合服装、遮罩或物理编排。28个条目包括隐藏足球扩展，不能说每个都在同一个公开菜单中。详见 [动作目录](action-catalog.md)。

首次运行有欢迎演出，默认无声、原地活动。沿边巡游、任务状态桥和开机启动均需自行开启。它不会自动知道 Codex/Claude 的真实任务状态。

Codex Mini 与独立桌宠可以同时存在；若只想看完整版，可自行隐藏 Mini。项目不会替用户切换现有宠物。

## 如果连基础动画也完全不动

[官方宠物说明](https://learn.chatgpt.com/docs/pets)说明宠物遵从操作系统的减弱动态设置，开启时会使用静帧。仅在确实完全静止时检查该设置；当前用户已经确认“会动”，不需要为缺少衣柜去修改系统动画偏好。
